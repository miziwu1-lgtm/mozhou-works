# 第2章 白光展开之处

> 摘要：埃弥安与管货人谈妥，以十二筐干货的装卸及途中归置清扫抵这一程船钱，装船后随船出发。他结识本趟领航的莉薇娅，途中看见包覆山地与灯火的透明石壳，也因看景耽误用筐、错放席捆堵住通道，随后与人合力纠正并完成整理清扫。莉薇娅讲述了自己补充物资、继续探路的打算。经过吃饭、休息和航行，船开始贴近白枝港；埃弥安准备卸货，尚未上岸，也未找到伊诺的店。

埃弥安走进棚下，鞋底带进来的水在石面上擦出一声轻响。长凳上的人正在分一块面包，先前那只挪到脚边的包还敞着口，里面的衣裳叠得整齐。这里没有人排队，靠水的一侧却堆着箱筐，只留下一条通往船边的窄路。

“去白枝港的货，搁这边。别跟刚卸下来的混在一起。”

管货的男人卷着袖口，正从货堆里往外抽一只空筐。他身后泊着一艘蒸汽船，舷边的灯照亮了岸上几级湿石阶。船上有人接东西，有人端着碗侧身让路；更远处，一个女人将纸卷摊在栏边，压住翘起的一角，抬头看向尘流。

白枝港。埃弥安刚才还一路念着这个名字，生怕忘了。那艘船还在装货，也许来得及。

两个搬货的人抬着一捆长席走来。前头的人倒退着走，后面的人被席捆挡住了视线，看不清脚下，叫同伴慢一点。埃弥安往棚柱旁挪开，粗硬的席边擦过他的衣袖。两人把席捆放到箱顶，挤占了半条窄路。其中一人甩了甩手，又绕到另一头，想找个方便搬动的位置。

管货人抽出了空筐，直起腰看向埃弥安，等他开口。

“我想搭船去白枝港。”埃弥安说，“船上的事我不熟。帮你搬货、打扫，能抵船钱吗？”

男人把筐放下，指了指柱后的货物。

“这十二筐干货，你帮我搬上去。船上有人告诉你搁哪儿。路上把货归置好，掉下来的碎屑也扫一扫。到了白枝港，还得帮我卸这十二筐。机器用不着你碰。”

“要走多久？”

“顺利的话，十八个钟头上下。有饭，舱里找地方睡，铺盖借你。先搬一筐试试，抬不动就放下。”

筐底刚离地，他就知道自己提着它上不了石阶。他把筐放回地上，从里面取出两小袋，分两趟送到管货人指的舱门边，再回来搬剩下的。

等最后一筐货交到船上，他的双臂已经发酸。棚下还剩席捆和几只大箱。管货人朝船上一扬下巴，示意他可以上去了。

他经过那个摊着纸卷的女人身旁时，纸的一角正被风掀起。他伸手压住。她取来夹子，夹好纸角，他才松开手。

“谢谢。你到哪一站？”

“白枝港。我叫埃弥安。”

“莉薇娅。往这边让让，我要开你脚边的舱口。”

他往旁边让开，莉薇娅掀起舱口的门板，向舱里的人问了两句。得到回答后，她放下门板，才把纸卷挪到另一段栏杆旁。纸上的线条旁写着密密的小字，到末端却空了一大片。

“你也去白枝港？”

“去，在那儿停一站，还要接着走。”她夹好纸，“这趟我领航。有东西不知往哪儿放，问管货的，别看见空地就搁。”

余下的席捆和大箱也搬上了船。脚下传来低低的震动，船要出发了。岸上的人松开绳索，管货人也上了船。候船棚从舷边往后退；埃弥安认出那根棚柱，柱旁的水痕已看不清了。再过一阵，工坊所在的一排灯融在一起，他找不到那道门。

尘流在船前显出宽窄不一的亮带。先前从岸上看见的那点白光，出现在船头前方，仍像停在原处。

“那是白枝港吗？”他问。

莉薇娅顺着他的目光看了一眼。

“不是。我们从它外面经过，再往前才到白枝港。”

“那点白的究竟是什么？”

“等前面这片尘流过去，就能看清些了。”

她正比对纸上的标记，没再说。埃弥安还得把舱门边的货归置好。他抱起一袋干货送进舱里，放到指定的位置，又出来取下一袋。白光时而被船上的立柱遮住，时而从两根柱子之间露出；他开始能分辨，它并非一个圆点，一侧拖着极细的弧。

吃过第一顿饭，那道弧仍没有到头。

他端着洗净的碗站在栏边，看那道白色的弧从船头前方一直延伸到高处。原先挤在一起的几团亮光渐渐分开，中间露出了暗色的山脊。一片发光的尘流从眼前移开，他才看清：那些山与灯火，原来被一层透明的石壳包在里面。白光沿着石壳弯曲的边缘延伸。更远的地方没有亮起来，仍隐在黑暗中。

石壳里，一面山坡上散着灯，山坡后方还有灯火。先前他以为那些灯挨得很近，如今才看见中间隔着一座山谷。船已经走了这么久，远处的谷底看起来却还只有一线宽。

“里面住着人？”他脱口问。

“有港口，也有往里的路。我们这次不进去。”

他还想找找那些路在哪里。放好碗后，他拿起一只空筐，要送到舱门口，却又抱着它停在栏边。管货人在舱门口叫了他两遍，他才回过神。

“那只筐要用。别带着它看风景。”

埃弥安赶忙把筐送到舱门口，搁在那人脚边。那人总算能把怀里的布袋放进筐里，腾出手来揉揉勒红的手腕。埃弥安说了声抱歉，回头去搬席捆。他图省事，抬起一头，把它拖到舱门口横着一搁，想先搬完轻货再来挪它。

没过多久，端饭的人出不来了。

端饭的人已经把托盘伸出了门，脚下却被席捆挡住。管货人想从另一边过去，那里也堆着没放好的筐。端饭的人只好退回舱里。

“我让你放门里靠墙。”管货人看着埃弥安，“搁在这儿，它还能自己挪过去？”

埃弥安弯腰抱住席捆的一端，提起来往门里挪，另一端仍拖在地上。刚转了半步，席捆就碰上门框。他立刻放下，没再硬拽，抬头朝莉薇娅那边望去。

船头传来莉薇娅的声音：“这段别叫我，等我看过前面的岔流。”

她站在更前面的栏边，一会儿低头看纸，一会儿抬头望向两道相叠的亮带。埃弥安收回目光，先把挡路的小筐提进舱里，找好靠墙放席捆的地方，再去请管货人帮忙。

“我一个人搬不进去。能帮我抬一下那头吗？”

“这回看好地方了？”

他指了指门里靠墙的空处，又把碍脚的散绳收进筐里。男人走到席捆另一端，叫他听口令，两人一起抬起。抬到门口转向时，埃弥安看不见身后的门框，便先停住，等管货人告诉他该往哪边挪。两人把席捆放到墙边，他的手指已被粗席磨得发烫。门口总算空了出来。

他没再去看白光，先把剩下的几筐货放到管货人指过的位置，又拿扫帚扫净地上的碎屑。有人端着饭从身边过去，这回没再停。

等他把扫帚挂好，回到栏边，石壳发亮的边缘已经到了船后。山挡住了先前最亮的地方，只有高处还露着一抹白。

他踮起脚，从栏杆上方望过去。山后的灯已经看不见了。

莉薇娅回来收纸卷，把带来的两杯水放在手边。见他还望着船后，她说：“想看刚才那片灯？船已经开过去了。”

“我知道。”

“刚才怎么不先把筐送过去？”

“我本来只想看一眼。”

“我头一回看，也舍不得走。”她把夹子一个个取下来，放到手边，“可刚才那个人抱着一大袋东西，就等你手里的筐呢。”

埃弥安没接话。莉薇娅把其中一杯水挪到他面前，自己拧开另一只杯子的盖。

“端饭的叫我带给你。别碰倒。”

他伸手拿杯子，指肚碰到杯壁，被粗席磨过的地方有些疼。他换了只手拿。莉薇娅瞧见了，往旁边让出一块能搁手肘的地方。

两人歇了一阵。船后的石壳越看越窄，里面那些刚分开的灯火，又渐渐挤在了一起。

“你第一次出来？”她问。

“第一次走这条路。”

“难怪。”

“你第一次看见的时候，也没挪开眼睛？”

“哪能一直看。”她喝了口水，“不过我那趟没你这么忙，回头还能再看两眼。”

他笑出声，随后放下水杯，活动了一下发酸的手臂。她也笑了，把杯子放回栏边，取过一只扁盒，打开盖子，让他替自己扶着，往里面放收好的夹子。

“这个我能拿稳。”他说。

“好，那就交给你了。”

莉薇娅合上盒子，从他手里接过来，搁在栏边，没有马上走。埃弥安看向那卷纸露在外面的空白。

“过了白枝港，你还往哪儿走？”

她松开卷边，将纸展开一点，给他看最后几行标记。

“上回走到这儿，带的东西不够，只好回头。我想再去一趟。把路走通了，以后有人问，我也能给他指条准路。”

“这次能走通吗？”

她的拇指停在纸边。

“先在白枝港把东西备齐吧。前面能不能走，到了才知道。”

“可你还想去。”

“很想。”她答得很快，随即把纸卷紧，“我得留神点。不然，看见点光，都能觉得那里有路。”

船后的石壳渐渐远了。方才望着石壳，他只盼船能再靠近些。现在才想起，他连里面的港口叫什么都没问。

后来，莉薇娅去休息，换了人守在前头。他将借来的铺盖展开，睡在舱里的一块空处。醒来时，船还在震，手臂一抬便酸。旁边的人正卷铺盖，他也坐起来，把自己的叠好送回去。

吃过第二顿热饭，又走了好几个钟头，船头才有人指着前面说：“看，前面就是白枝港。”

起先是一道低低的灰白。随着船走近，枝条从中一根根分出，露出后面的深色树干。那些树没有把旧星骸遮完，林间仍能看见大片裸露的黑石；更高处，一条裂隙穿过石壁，枝影细细地横在裂隙上。

埃弥安往舷边挪了半步。这次双手是空的。

临水的屋顶从白枝下显出，接着是门窗、石阶和靠在岸边的船。几棵矮树紧挨着上岸的路，其中一根枝条已经伸过台阶边沿。他想起玛蕾特说过的树：她来时，有几棵树才刚长过石阶。现在隔着水，他还分不清眼前的是不是她说过的那几棵。

管货人招呼他准备卸货。他回舱检查十二只筐，将自己能搬的轻袋放到靠外处，重筐留在原处，等人帮着一起抬。借来的杯子和铺盖都已归还，他没有别的东西要拿。

莉薇娅从船头回来，指了指临水的一排屋子：“从那边上岸。先等他们把路腾出来。”

“我想找伊诺的店。修船的玛蕾特说，就在那排屋子里，门边有长凳。等上岸了再问问。”

莉薇娅朝那排屋子看了一眼。

船正慢慢贴近石岸。埃弥安抓住一只筐的提手，等船上的人叫他动手。屋前有几条长凳，此刻都空着；更里面，有人推开了一扇门。
